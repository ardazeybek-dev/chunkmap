Chunk size distribution

01 · CHUNK

Content-defined boundaries

Every file is cut with FastCDC: a Gear rolling hash picks boundaries from the bytes themselves, so an insertion only changes nearby chunks.

02 · HASH

BLAKE3 fingerprints

Each chunk and each whole file is fingerprinted with BLAKE3 in one parallel pass. Every byte is read exactly once.

03 · MATCH

Index & attribute

A global chunk index counts what's stored twice, groups identical files and pairs files that share content.
